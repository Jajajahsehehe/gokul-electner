## 🚀 Featured Project

### 🗑️ BinNova — Smart IoT Waste Management System

> An ESP32-powered system that monitors bin fill levels in real time using ultrasonic sensors,
> syncs data to Firebase, and displays insights on a citizen web map and municipal dashboard.

| Feature | Detail |
|---|---|
| 📡 Sensors | Ultrasonic (HC-SR04) + IR proximity |
| ☁️ Cloud | Firebase Realtime Database |
| 🌞 Power | Solar dual-battery system |
| 🔔 Alerts | Smart notifications at 80% capacity |
| 🗺️ Interface | Citizen map + Municipal dashboard |

[![BinNova Repo](https://img.shields.io/badge/View_Project-BinNova-7F77DD?style=for-the-badge&logo=github)](https://github.com/gokul-electner/binnova)
